# 非機能要件

[← 要件定義書に戻る](00_要件定義書.md)

最終更新日: 2026-11-06

初級課題の範囲で、安全に・迷わず使えることを優先する。

| 区分 | 要件 |
| --- | --- |
| 性能 | 一覧・詳細ページは通常の回線で3秒以内に表示する |
| セキュリティ | パスワードはハッシュ化して保存する |
| セキュリティ | 他人のレシピの編集・削除URLに直接アクセスしても実行できない |
| セキュリティ | 入力値はエスケープして表示し、XSSを防ぐ |
| セキュリティ | CSRF 対策を入れる。API はフロントエンドの URL からのアクセスだけを許可する（CORS 設定） |
| ユーザビリティ | 全ページ共通のヘッダーからトップ・登録・ログインに移動できる |
| ユーザビリティ | 登録・更新・削除の後に完了メッセージを表示する |
| ユーザビリティ | 入力エラーは日本語で表示し、入力した内容は消さない |
| 対応環境 | PCのChrome最新版を基本とし、スマートフォン幅（375px）でもレイアウトが崩れない |
| 画像 | アップロードは jpg / png、1枚 5MB まで（F-12 を実装する場合） |
| 保守性 | Gitでバージョン管理し、機能ごとにコミットする |
| 保守性 | README に起動手順を書く。API の動作は自動テストで確認できるようにする |
